# Cloudflare R2 Dual-Bucket Setup & CORS Guide

This guide describes how to configure the Cloudflare R2 storage buckets for the Investra platform.

---

## 1. Create the R2 Buckets

Investra uses two physically isolated buckets:

1. **Public Bucket:** `investra-media-public`
   - Stores user avatars, campaign cover banners, pitch galleries, and public videos.
   - **Access:** Enable Cloudflare's free `r2.dev` public development URL, or attach a custom domain (e.g., `cdn.investra.com`).
   - Set the `R2_PUBLIC_URL` environment variable to this domain without a trailing slash (e.g. `https://pub-xxxxxx.r2.dev`).

2. **Private Bucket:** `investra-media-private`
   - Stores KYC verification documents (NIDs, passports), confidential pitch decks, and financial statements.
   - **Access:** Keep public access **disabled**. No public subdomain or public URL is assigned.
   - Access is permitted solely through 15-minute temporary Presigned GET URLs generated by the NestJS backend.

---

## 2. CORS (Cross-Origin Resource Sharing) Configuration

Because clients upload files **directly from the browser to Cloudflare R2 via HTTP PUT**, both buckets must have CORS configured.

In the Cloudflare Dashboard:
1. Navigate to **R2 Storage** -> Click on the bucket (`investra-media-public` or `investra-media-private`).
2. Go to **Settings** -> Scroll to **CORS Policy** -> Click **Add CORS Policy**.
3. Paste the following JSON:

```json
[
  {
    "AllowedOrigins": [
      "http://localhost:3000",
      "http://localhost:3001",
      "https://investra.vercel.app",
      "https://investra-frontend-4m5v.onrender.com"
    ],
    "AllowedMethods": [
      "GET",
      "PUT",
      "HEAD"
    ],
    "AllowedHeaders": [
      "*"
    ],
    "ExposeHeaders": [
      "ETag"
    ],
    "MaxAgeSeconds": 3600
  }
]
```

> **Security Note:** In production, replace `*` in origins with your explicit production frontend domains. Do not use wildcard `*` origins in production.

---

## 3. Generate R2 API Tokens

1. In the Cloudflare Dashboard, go to **R2** -> **Manage R2 API Tokens**.
2. Click **Create API Token**.
3. Select **Admin Read & Write** permissions (Object Read & Write) scoped to both `investra-media-public` and `investra-media-private`.
4. Copy the following credentials into your backend environment:
   - `R2_ACCOUNT_ID`: Your Cloudflare Account ID (found on the R2 overview page).
   - `R2_ACCESS_KEY_ID`: The Access Key ID generated.
   - `R2_SECRET_ACCESS_KEY`: The Secret Access Key generated.
   - `R2_ENDPOINT`: `https://<R2_ACCOUNT_ID>.r2.cloudflarestorage.com`
